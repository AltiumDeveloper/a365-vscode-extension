## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| in-process consumer → SecretStorage | TokenSet JSON serialized into VS Code SecretStorage (OS keychain) |
| id_token issuer → extension | JWT signature is NOT verified (claims read decoratively for UI label only) |
| auth-state subscribers (statusBar.ts, sidePanel.ts) | receive AuthState; user/environment are display-only strings |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Information Disclosure | per-workspace token cache | mitigate | `context.secrets` only (OS keychain); never `globalState`/`workspaceState` for tokens. Index in globalState contains only workspaceIds (opaque server IDs), never token material. |
| T-02-02-02 | Spoofing (stale token after sign-out) | leftover prefix keys after `clearAllTokens` | mitigate | `clearAllTokens` iterates the globalState index and deletes every `altium365.workspaceTokens.<id>` key, then clears the index. Legacy `altium365.workspaceTokens` singleton key is also deleted to cover upgrade case (RESEARCH.md §Runtime State Inventory). |
| T-02-02-03 | Elevation of Privilege (cross-workspace token reuse) | cache key keyed by workspaceId | mitigate | Cache key = `SECRET_WS_TOKEN_PREFIX + workspace.workspaceId`. `ensureWorkspaceToken` takes the workspace object, never accepts a token from one workspace for another. Code-review checkpoint in PR. |
| T-02-02-04 | Tampering (malformed id_token causes crash) | `decodeIdTokenClaims` | mitigate | All JSON.parse and base64 decode wrapped in try/catch returning undefined; getActiveUserLabel falls back to `'(signed in)'`. JWT signature not verified — claims are display-only, not authorization decisions. |
| T-02-02-05 | Spoofing (display label phishing) | user label rendered in status bar | accept | Label sourced from server-issued id_token claims; if IdP issues a deceptive label, that is an IdP trust issue, not a client-side mitigation. |
