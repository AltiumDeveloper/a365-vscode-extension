Two unrelated hygiene fixes co-located because they touch the same file and have no behavioural interaction:
  - D-11 (WR-01): escape the OAuth `error` query param before interpolating into the loopback HTML error page (XSS hardening — a malicious redirect cannot inject script into the loopback response).

Purpose: defensive hardening before Phase 3 introduces remote script mutations that compound the consequence of any auth-surface bug.
Output: a local non-exported `escapeHtml` in `src/auth.ts`, used in the awaitCallback error branch; a `.slice(0, 500)` applied at the postForm error throw site.
