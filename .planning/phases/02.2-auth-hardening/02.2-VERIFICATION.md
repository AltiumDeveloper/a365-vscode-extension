## Human Verification Required

The phase ships a deliberately manual UAT (per D-13 / D-14 — no telemetry hooks). Five scenarios are scripted in `02.2-UAT.md`. Each maps to ≥1 in-scope finding:

### 1. Account switch without explicit sign-out (CR-02 / D-05, D-06)
**Test:** Sign in as identity A, expand a workspace, then sign in as B without signing out first; refresh and re-expand.
**Expected:** Fresh exchange under B; A's `altium365.workspaceTokens.*` entries absent; no UI flicker to signed-out state.
**Why human:** Requires two real identities + visual confirmation of no tree-collapse flicker mid-sign-in.

### 2. Parallel workspace expansion (WR-05 race / D-07 dedup)
**Test:** Refresh tree, immediately expand 3+ workspaces in rapid succession.
**Expected:** Exactly N exchanges (one per workspace), no duplicates; index ends up with N IDs.
**Why human:** Requires manual rapid clicks + inspection of network log / OutputChannel timing.

### 3. Expired base token triggers refresh (WR-02 / D-09)
**Test:** Manually edit `expires_at` to past in SecretStorage, then refresh tree.
**Expected:** `refresh_token` grant fires transparently; tree loads; no 401, no re-sign-in prompt.
**Why human:** Requires SecretStorage edit via Dev Tools + network-log observation.

### 4. `listWorkspaces` always uses base token (WR-05-CARRY / D-03, D-09, D-10)
**Test:** With a workspace selected, refresh tree and inspect the `Authorization` header on the `desWorkspaceInfos` request.
**Expected:** Bearer token's JWT payload lacks any `a365:workspace:<authId>` scope claim.
**Why human:** Requires JWT-decoding the live network request body.

### 5. OAuth error XSS hardening (WR-01 / D-11)
**Test:** Manually craft `?error=<img src=x onerror=alert(1)>` on the loopback callback URL.
**Expected:** Page renders literal escaped text; no `alert(1)`; no script execution.
**Why human:** Requires interactive browser navigation + observation of no script execution.

### Regression (ROADMAP SC-4)

**Expected:** All pass — no regression in OAuth2 PKCE flow, sign-in/sign-out, or per-workspace token cache.
