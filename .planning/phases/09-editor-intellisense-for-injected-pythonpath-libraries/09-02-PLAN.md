<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user consent → workspace configuration write | The extension must not mutate `python.analysis.extraPaths` until the user explicitly allows it. |
| extension host → optional Python/Pylance extensions | Tooling presence influences editor UX but must not become a runtime dependency. |
| `altium365.injectHelper` toggle → managed path cleanup | Disabling helper injection must only remove extension-owned entries from shared settings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Tampering | `python.analysis.extraPaths` update path | mitigate | Gate first write behind a one-time prompt per D-05 and use 09-01's previous-managed snapshot removal so user-owned entries survive per D-11/D-12. |
| T-09-05 | Denial of Service | missing Python/Pylance tooling | mitigate | Probe `ms-python.python` and `ms-python.vscode-pylance` on activation, warn proactively per D-09, and keep runtime run/debug flows untouched per D-08. |
| T-09-06 | Tampering | drift-heal on activation/config change | mitigate | Reconcile from the current canonical managed-path list and the stored prior-managed snapshot so updates self-heal only extension-owned paths per D-13. |
| T-09-07 | Spoofing | explicit command / prompt actions | mitigate | Bind all enable/disable/repair flows to the single contributed command id `altium365.configurePythonIntelliSense` and log decisions to the existing OutputChannel for traceability. |
| T-09-SC | Tampering | npm installs | accept | No package-manager installs in this plan. |
