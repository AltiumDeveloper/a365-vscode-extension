<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| extension host → managed path calculator | Local code turns extension install paths into editor-analysis roots. |
| reconciliation engine → user-owned setting values | Untrusted existing `python.analysis.extraPaths` values must be preserved while only extension-owned entries are manipulated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | `reconcilePythonAnalysisPaths` | mitigate | Remove only the stored previous managed set and preserve all other entries verbatim per D-11/D-12. |
| T-09-02 | Tampering | `getManagedPythonAnalysisPaths` | mitigate | Derive managed paths only from `context.asAbsolutePath(...)` and existing sandbox helpers; do not accept arbitrary user-supplied path roots. |
| T-09-03 | Denial of Service | duplicate/unstable path merge | mitigate | Normalize and dedupe managed paths so repeated activation or drift-heal does not bloat `python.analysis.extraPaths`. |
| T-09-SC | Tampering | npm installs | accept | No package-manager installs in this plan. |
</threat_model>
