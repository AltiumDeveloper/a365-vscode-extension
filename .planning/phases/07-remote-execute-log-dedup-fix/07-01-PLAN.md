# Plan 07-01: dedupLogPage extraction, integration, and unit test

## Goal

Eliminate the ~3× log-line duplication observed during remote script execution by (a) extracting a pure `dedupLogPage` helper, (b) integrating it into `pollExecutionLoop` and removing the buggy `if (logPage.nextToken)` cursor-advance guard, (c) covering the helper with a vitest unit test. - D-04: Scope is dedup only. Do not touch status-flip cadence, footer, error backoff, or Promise.all ordering.

### Task 1 — Extract `dedupLogPage` helper and integrate into `pollExecutionLoop`

<read_first>
- `src/remoteExecution.ts:240-317` (full `runPollLoop`)
- `src/workspace.ts:514-547` (`ExecutionLogPage` shape)
</read_first>

<action>
1. In `src/remoteExecution.ts`, add a top-level pure function (export it so Task 2 can import):
   ```ts
   export function dedupLogPage(
     returnedLogs: readonly string[],
     printedCount: number
   ): { fresh: string[]; newPrintedCount: number } {
     if (returnedLogs.length <= printedCount) {
       // Defensive: server returned fewer lines than we've already printed.
       // Treat as no-op; keep printedCount stable (do NOT shrink).
       return { fresh: [], newPrintedCount: printedCount };
     }
     return {
       fresh: returnedLogs.slice(printedCount),
       newPrintedCount: returnedLogs.length,
     };
   }
   ```
2. In `runPollLoop`:
   - Replace `let nextToken: string | null = null;` with `let printedCount = 0;`.
   - Replace the `getExecutionLogs(..., nextToken)` call with `getExecutionLogs(..., LOG_PAGE_LIMIT, null)` — we no longer pass a cursor (server re-sends from start; dedup handles it).
   - Replace the loop `for (const line of logPage.logs) { args.output.appendLine(line); }` + `if (logPage.nextToken) { nextToken = logPage.nextToken; }` block (current lines 289-294) with:
     ```ts
     const { fresh, newPrintedCount } = dedupLogPage(logPage.logs, printedCount);
     for (const line of fresh) {
       args.output.appendLine(line);
     }
     printedCount = newPrintedCount;
     ```
3. Leave everything else in `runPollLoop` untouched (Promise.all, status-flip log, terminal-check order, footer, cancellation path, `MAX_WALLCLOCK_MS` backstop).
4. Run `npm run compile` — must pass with zero new errors.
</action>

### Task 2 — Unit test `test/dedupLogPage.test.ts` (5 cases)

<read_first>
- `src/remoteExecution.ts` (post-Task-1) to import `dedupLogPage`
- `vitest.config.ts` (from Task 0)
</read_first>

<action>
1. Create `test/dedupLogPage.test.ts`:
   ```ts
   import { describe, it, expect } from 'vitest';
   import { dedupLogPage } from '../src/remoteExecution';

   describe('dedupLogPage', () => {
     it('empty first page → no output, count stays 0', () => {
       const r = dedupLogPage([], 0);
       expect(r.fresh).toEqual([]);
       expect(r.newPrintedCount).toBe(0);
     });

     it('first page with 3 lines → all printed, count = 3', () => {
       const r = dedupLogPage(['a', 'b', 'c'], 0);
       expect(r.fresh).toEqual(['a', 'b', 'c']);
       expect(r.newPrintedCount).toBe(3);
     });

     it('second page repeats prefix + adds 2 new → only the new tail emitted', () => {
       const r = dedupLogPage(['a', 'b', 'c', 'd', 'e'], 3);
       expect(r.fresh).toEqual(['d', 'e']);
       expect(r.newPrintedCount).toBe(5);
     });

     it('defensive: server returns fewer lines than printedCount → no output, count unchanged', () => {
       const r = dedupLogPage(['a', 'b'], 5);
       expect(r.fresh).toEqual([]);
       expect(r.newPrintedCount).toBe(5);
     });

     it('final batch after terminal status: full transcript returned → only un-printed tail emitted', () => {
       const r = dedupLogPage(['a', 'b', 'c', 'd', 'e', 'f'], 4);
       expect(r.fresh).toEqual(['e', 'f']);
       expect(r.newPrintedCount).toBe(6);
     });
   });
   ```
2. Run `npm run test` — must exit 0 with 5/5 passing.
3. Run `npm run compile` — must still pass.
</action>
