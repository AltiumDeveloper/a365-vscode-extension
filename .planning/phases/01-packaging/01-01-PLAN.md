    Step B — Create `scripts/generate-icon.js`:
    Create the directory `scripts/` and write `scripts/generate-icon.js` as a self-contained Node.js script (no npm dependencies — uses only built-in `zlib`, `fs`, `path`). The script must:
    1. Create the `resources/` directory if it does not exist.
    2. Generate a 128×128 RGBA pixel buffer. Draw a monochrome circuit-board motif on a transparent background: foreground pixels are RGBA(220, 220, 220, 255), background pixels are RGBA(0, 0, 0, 0). The design should consist of:
       - A bold outer ring (annulus) centered at (64,64) with outer radius 58 and inner radius 50
       - Four rectangular "trace" lines extending from the ring to the edges: top (x=60-68, y=6-50), bottom (x=60-68, y=78-122), left (y=60-68, x=6-50), right (y=60-68, x=78-122)
       - Four filled square "pad" nodes at the trace endpoints: 12×12 squares at corners (58-70, 0-12), (58-70, 116-128), (0-12, 58-70), (116-128, 58-70) — but inset 6px from edge, i.e. at (58,6), (58,110), (6,58), (110,58) as top-left corner, each 12×12
       - A small filled circle at center (64,64) with radius 8
    3. Build a valid PNG binary: IHDR chunk (width=128, height=128, bitDepth=8, colorType=6 RGBA), IDAT chunk (deflate-compressed scanlines with filter byte 0x00 prepended to each row), IEND chunk.
    4. Write the PNG bytes to `resources/icon.png`.
    5. Print `resources/icon.png written (NNN bytes)` on completion.

    PNG binary construction requirements:
    - PNG signature: bytes `[137, 80, 78, 71, 13, 10, 26, 10]`
    - Each chunk: 4-byte big-endian length, 4-byte type, data, 4-byte CRC32 (use the standard PNG CRC32 over type+data)
    - IHDR data: width (4B BE), height (4B BE), bitDepth=8 (1B), colorType=6 (1B), compression=0 (1B), filter=0 (1B), interlace=0 (1B)
    - IDAT: prepend filter byte 0x00 to each row's 512 bytes (128 pixels × 4 channels), then zlib.deflateSync the concatenated filtered scanlines
    - CRC32: implement via the standard polynomial 0xEDB88320 table lookup (the standard PNG CRC32)

    Step C — Run the generator:
    Execute `node scripts/generate-icon.js` to produce `resources/icon.png`.
    Verify the file exists and is non-empty before proceeding.

    Run `npm run package` from the project root. This will call `vsce package` which internally calls `vscode:prepublish` (= `npm run compile`), then packages the output into a `.vsix`. The command must exit 0.
