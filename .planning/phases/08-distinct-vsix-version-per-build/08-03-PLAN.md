<objective>
Add the VS Code integration layer for the self-updater: `src/updater.ts` exposing `registerUpdater(context, outputChannel): Disposable[]` that wires both the activation-time auto check (debounced 24h, gated on the `altium365.checkForUpdates` setting) and the manual `altium365.checkForUpdates` command. Wire the factory into `src/extension.ts` alongside the existing `register*Commands` calls, and declare the new command + setting in `package.json`.

Purpose: This is the user-facing payoff for Phase 8. The CI from 08-01 produces uniquely-versioned VSIXes on every push to main; the helper from 08-02 can decide which version is newer; this plan closes the loop by polling the GitHub Releases API, comparing against the installed version, and offering a one-click install + reload flow.

Output: An extension that, on activation (with default settings), silently checks GitHub once per 24h and surfaces a toast when a newer release exists; a palette-visible "Altium 365: Check for Updates" command that bypasses the debounce and gives explicit feedback either way.
</objective>
