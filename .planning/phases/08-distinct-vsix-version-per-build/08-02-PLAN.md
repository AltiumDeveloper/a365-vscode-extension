export interface ParsedVersion {
    major: number;
    minor: number;
    patch: number;
    pre: Array<number | string>;  // empty array = NOT a pre-release

export function parseVersion(v: string): ParsedVersion | null;
export function compareVersions(a: string, b: string): number;  // negative if a<b, 0 if equal, positive if a>b

6. **Exported `compareVersions(a: string, b: string): number`** implementing SemVer §11 in this order:
   - Parse both; if either is `null`, return `0` with a comment explaining the safe-fallthrough rationale (no false update prompt on malformed remote data).
   - Compare `major`, then `minor`, then `patch` (numeric subtraction).
   - If both `pre` arrays empty → return 0.
   - If only `a.pre` empty → return positive (normal > pre-release of same base).
   - If only `b.pre` empty → return negative (mirror).
   - Loop `i` over `min(a.pre.length, b.pre.length)`:
     - Equal identifiers → continue.
     - Both numeric → numeric subtraction.
     - One numeric, one alphanumeric → numeric is lower (§11.4.3).
     - Both alphanumeric → ASCII lexicographic compare.
   - All compared identifiers equal → return `a.pre.length - b.pre.length` (§11.4.4 — longer wins).
7. **Style:** named exports only (no default), 4-space indent, single quotes, `interface ParsedVersion`, no `type` aliases (per CONVENTIONS.md).
