  <pinned-contract date="2026-05-20" source="live dev1 portal smoke-probe by operator">
    ### Files Service REST contract — PINNED (operator-captured)

    Base URL: `WorkspaceInfo.location.filesServiceUrl` (per-workspace, fetched via `listWorkspaces` query bump in Task 2). No env-global fallback.

    **DOWNLOAD (read script body)**
    - URL: `${filesServiceUrl}/File/Download?id=${fileToken}`
    - Method: `GET`
    - Headers:
      - `Authorization: Bearer ${workspaceToken}` (same token as per-workspace GraphQL — `ensureWorkspaceToken(ctx, ws)`)
    - Response Content-Type: `application/octet-stream`
    - Response body: raw script source bytes

    **UPLOAD (publish edited script body)**
    - URL: `${filesServiceUrl}/File/Upload`
    - Method: `POST`
    - Headers:
      - `Authorization: Bearer ${workspaceToken}`
      - `Content-Type: multipart/form-data; boundary=...` (boundary auto-generated; do NOT set Content-Type manually when using `FormData` — let the runtime set it)
    - Request body: `multipart/form-data` with a single part:
      - field name: `file` (standard)
      - filename: any non-empty string (e.g. the script's `.py` name); the server treats the body bytes as the new content
      - body bytes: the script source
    - Response Content-Type: `text/plain` (or similar; treat as text)
    - Response body: the new `fileToken` as a **plain UUID string** (e.g. `3038c52a-c406-443e-a88b-18205cf6c938`) — NOT JSON-wrapped. Caller passes this token straight into the subsequent `gloScrUpdateScript` mutation.

    **Token shape**: UUID-v4. Path-traversal regex in Task 3 should be `/^[A-Za-z0-9-]+$/` (UUID hex + dashes only) — tighter than the original draft.

    **Auth tier**: workspace-scoped, NOT base. Resolve via `ensureWorkspaceToken(ctx, ws)` at every call (D-08).
  </pinned-contract>
