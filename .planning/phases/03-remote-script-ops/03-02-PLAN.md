  <name>Task 1: New module — src/remoteScriptFs.ts (FSP skeleton + URI helpers)</name>
  <files>src/remoteScriptFs.ts</files>
  <action>
    Implement per `<interfaces>` above. URI shape (D-01): `altium365://<workspaceId>/<scriptId>/<scriptName>.py`.

    - `buildScriptUri(wsId, scriptId, scriptName)` — uses `vscode.Uri.from({ scheme: 'altium365', authority: wsId, path: '/' + scriptId + '/' + encodeURIComponent(scriptName) })`. Document why `authority` carries the workspaceId (host-segment) and the path carries `scriptId` + display name.
    - `parseScriptUri(uri)` — strict parse: scheme must be `altium365`; `authority` must be a UUID-shaped string (regex `/^[0-9a-fA-F-]{36}$/`); first path segment must be UUID-shaped scriptId; remainder is `displayName` (decoded). On any mismatch throw `vscode.FileSystemError.FileNotFound(uri)` (security V5 / threat T-03-02-01). Per RESEARCH §Security Domain.

    - `AltiumRemoteScriptFs` class:
      - `private _onDidChangeFile = new vscode.EventEmitter<vscode.FileChangeEvent[]>()`; expose `.event` as `onDidChangeFile`.
      - `watch()` returns `new vscode.Disposable(() => {})` — no-op v1 (D-03).
      - `stat(uri)` returns `{ type: vscode.FileType.File, ctime: 0, mtime: Date.now(), size: 0, permissions: undefined }`. Size 0 is fine — VS Code uses readFile result for actual buffer size.
      - `readDirectory(uri)` — throw `FileSystemError.FileNotADirectory(uri)`.
      - `createDirectory(uri)` — throw `FileSystemError.NoPermissions(uri)`.
      - `delete(uri)` / `rename(uri)` — throw `FileSystemError.NoPermissions(uri)` (out of scope per Deferred: SCRIPT-V2-02).
      - `readFile(uri)` — **STUB** in this plan: throw `FileSystemError.Unavailable('readFile not yet implemented (Plan 03-03)')`. Plan 03-03 replaces this body.
      - `writeFile(uri, content, options)` — **STUB** in this plan: throw `FileSystemError.Unavailable('writeFile not yet implemented (Plan 03-03)')`. Plan 03-03 replaces this body.

    Constructor stores `ctx`, `getEnvGlobalEndpoint`, `output` for use by 03-03's real impl. Do not cache tokens or workspace info (D-08).

    File header JSDoc: cite D-01, D-03, D-07, D-08, and the security mitigations (T-03-02-01 path traversal, T-03-02-02 cross-workspace via re-resolve).
  </action>
