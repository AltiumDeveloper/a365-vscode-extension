<interfaces>
Optional small helper added to `src/scriptCommands.ts` (or co-located in a small new section — same file, no new module):

```ts
/**
 * Map a known A365 GraphQL error code to a user-friendly toast message.
 * Unknown codes fall through to the raw message. Full body is always logged
 * to OutputChannel by the caller (D-11).
 */
function mapGraphQLErrorToUserMessage(code: string | undefined, rawMessage: string): string;
```

Mapping table (curated from RESEARCH §Common Pitfalls + Phase 02 OAuth-error pattern, commit `a00dcc0`):

| code (case-insensitive)       | user-facing message                                                                 |
|-------------------------------|-------------------------------------------------------------------------------------|
| `AUTH_NOT_AUTHENTICATED`      | "Altium 365 session expired. Sign out and sign in again, then retry."               |
| `UNAUTHORIZED`                | "Altium 365: not authorized for this workspace. Switch workspace and retry."        |
| `BAD_USER_INPUT`              | "Altium 365 rejected the input. Check parameter values and try again."              |
| `NOT_FOUND`                   | "Altium 365: resource not found (it may have been deleted). Refresh the side panel." |
| (unknown / undefined)         | rawMessage                                                                          |

Codes confirmed in 03-03 / 03-04 UAT can be added here; codes not confirmed get NO mapping (fall-through to raw message) — better to leak an internal code than misclassify a failure.

    ```ts
    } catch (e) {
        const err = e as Error & { code?: string };
        const code = (err as any).code;        // GraphQLError carries .code (Plan 03-01 widening)
        const userMsg = mapGraphQLErrorToUserMessage(code, err.message);
        outputChannel.appendLine('[Altium 365] ' + COMMAND_NAME + ' failed: ' + err.message + (code ? ' (code=' + code + ')' : ''));
        // Also append the raw error stack to OutputChannel for diagnosis (D-11):
        if (err.stack) { outputChannel.appendLine(err.stack); }
        vscode.window.showErrorMessage('Altium 365: ' + userMsg);
    }
    ```
