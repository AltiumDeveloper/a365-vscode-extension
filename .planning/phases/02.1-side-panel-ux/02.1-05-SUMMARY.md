# Phase 02.1 Plan 05: Open in Browser for workspace + project — Summary

**Right-clicking a workspace or project in the side-panel tree now exposes an `Open in Browser` action that opens the node's A365 web URL via `vscode.env.openExternal`, sourced from a new `url` field added to the `desWorkspaceInfos` / `desProjects.nodes` GraphQL selections and carried end-to-end on the A365Node payload, with a graceful info-toast fallback when the backend omits the URL.**

## Accomplishments

- G-05 / PANEL-11 closure: workspace + project context menus include "Open in Browser"
- GraphQL `desWorkspaceInfos` and `desProjects.nodes` selections extended with `url`; `WorkspaceInfo.url?` and `ProjectInfo.url?` added (D-09); `LIST_SCRIPTS_QUERY` deliberately untouched (scripts are out of scope for G-05)
- Workspace + project A365Node union variants gain optional `url?: string`; propagated in `loadWorkspaces` (via `info.url`) and `loadWorkspaceChildren` (via `p.url`)

- Missing-url case shows `'This {workspace|project} does not expose a browser URL'` info toast; thrown errors surface a user-visible error toast plus stack to the OutputChannel

## Decisions Made

- **No extension.ts changes:** Frontmatter listed `src/extension.ts` in `files_modified`, but the plan body explicitly stated "no extension.ts changes" — the existing `registerTreeCommands` wiring from Plan 02.1-03 Task 4 already spreads the returned disposables into `ctx.subscriptions`, so adding more handlers to the factory's returned array is fully sufficient. Followed the plan body (and per-objective override).
- **Group naming `9_open`:** Sibling of Plan 02.1-03's `9_clipboard` — both render at the bottom of the menu, below the existing `1_run` / `2_edit` script-action groups. `_clipboard` precedes `_open` alphabetically within the `9_` numeric tier, which is acceptable visual ordering.
- **Missing-url fallback:** Info toast `'This {workspace|project} does not expose a browser URL'`, per the plan's explicit instruction "Do NOT silently fall back to a hand-constructed URL." Backend is the source of truth.
- **Defensive `node.kind` narrowing:** Even though contributes-menu `when`-clauses already restrict invocation, both handlers re-check `node?.kind` and log to OutputChannel on mismatch — pattern established as the canonical shape for handlers inside `registerTreeCommands`.
