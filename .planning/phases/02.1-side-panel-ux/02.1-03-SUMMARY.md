## Decisions Made

- **Toast on Copy ID:** Yes — CONTEXT.md the agent's discretion default. Brief `vscode.window.showInformationMessage('Altium 365: ID copied to clipboard')` confirms the action without being noisy.
- **Silent ignore on unsupported kinds:** No user-facing toast when handler is invoked with category/info/error/undefined kinds — `when`-clauses already prevent reachability; logged to OutputChannel only for diagnosis if it ever fires.
- **Group naming `9_clipboard`:** High group number reserves the area below existing `1_run`/`2_edit` script groups, matching CONTEXT.md `<specifics>` groupings note. Leaves `9_open` available for Plan 02.1-05's Open in Browser entries.
- **Module split:** Created `src/treeCommands.ts` as a sibling of `src/scriptCommands.ts` rather than folding into one — D-11 makes the boundary explicit (script-scoped vs tree-generic) and keeps both modules small.
