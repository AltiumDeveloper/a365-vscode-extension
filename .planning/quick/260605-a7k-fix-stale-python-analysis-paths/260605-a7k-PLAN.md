# Quick Task 260605-a7k: Fix stale Python analysis paths

## Goal

`python.analysis.extraPaths` in `.vscode/settings.json` accumulates paths from every
installed extension version. Root cause: when `globalState` is fresh (new machine /
profile reset / reinstall), `previousManagedPaths` is empty so existing extension
paths are treated as "user paths" and preserved while new paths are appended.

## Tasks

### Task 1 — Pattern-based stale path eviction in reconcileNow

**File:** `src/runner/pythonAnalysis.ts`

In `reconcileNow`, after reading `existingExtraPaths`, `previousManagedPaths`, and
`desiredManagedPaths`, add pattern-based stale detection **before** calling
`reconcilePythonAnalysisPaths`:

```typescript
// D-13 self-heal: also detect stale extension paths by pattern so a fresh
// globalState (e.g. new machine or profile reset) still evicts accumulated entries.
const STALE_EXTENSION_RE = /[/\\]extensions[/\\]altium\.developer-[^/\\]+[/\\]python/;
const desiredNormSet = new Set(desiredManagedPaths.map(normalizePath));
const staleDetected = existingExtraPaths.filter(
    (p) => STALE_EXTENSION_RE.test(p) && !desiredNormSet.has(normalizePath(p))
);
const prevManagedNormSet = new Set(previousManagedPaths.map(normalizePath));
const expandedPreviousManagedPaths = [
    ...previousManagedPaths,
    ...staleDetected.filter((p) => !prevManagedNormSet.has(normalizePath(p))),
];
// Use expandedPreviousManagedPaths in the reconcile call (not previousManagedPaths)
```

### Task 2 — Add unit test for stale eviction

**File:** `test/runner/pythonAnalysis.test.ts`

Add a test verifying that paths matching the altium.developer extension pattern but
NOT in `previousManagedPaths` are still evicted when `expandedPreviousManagedPaths`
is used. This test documents and guards the fix.

(Note: `reconcilePythonAnalysisPaths` is a pure function — the stale detection lives
in `reconcileNow`. The test should call `reconcilePythonAnalysisPaths` with the
expanded list to verify the removal logic, or test `reconcileNow` via the existing
integration-style test patterns.)

### Task 3 — Gitignore .vscode/settings.json + clean it

`.vscode/settings.json` contains only machine-local absolute extension paths.
It should never be committed.

1. Add `.vscode/settings.json` to `.gitignore`
2. Remove from git tracking: `git rm --cached .vscode/settings.json`
3. The file on disk will remain (VS Code needs it) but git stops tracking it
